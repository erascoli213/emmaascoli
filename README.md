# emmaascoli.design

Emma Ascoli's product design portfolio. A static React + Vite site hosted on GitHub Pages.

- **Publishing:** every push to `main` builds the site and publishes it (see `.github/workflows/deploy.yml`).
- **Images:** live in `public/images`. The one-time "Import images from Lovable" workflow copied them there.
- **Run locally:** `npm install --legacy-peer-deps`, then `npm run dev`.
