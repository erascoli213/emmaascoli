# Portfolio

A product design portfolio that matches the branding in the attached screenshot. I want it to be bubbly but modern.

Structure and preferences:
- Navigation format: Classic modern scroll
- Interactivity: Refined & tactile with pillowy buttons, gentle spring hover physics, and subtle doodle animations
- Initial content: 2 to 3 deep-dive product design case studies with problem framing, flows, and impact
- Structure: Keep the hero (matching the slide branding with warm cream, plum color block, navy serif typography, and doodle flourishes), case study grid, and process strip balanced around my work
